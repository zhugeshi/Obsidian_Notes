# TLS反调试
## 什么是TLS
TLS全称`Thread Local Storage`，即**线程局部存储**。

## 为什么需要TLS
TLS主要是为了解决多线程中变量的**同步**问题
			
进程中的全局变量和函数内定义的静态(static)变量，是每个线程都可以访问的**共享变量**。只要有任何一个线程修改了共享变量，其他所有线程中的共享变量也会**同步被修改**

乍看之下，这种方式使得**数据交换十分的便捷**，无需额外的通信就可以实现数据之间的交换。但`命运赠送的礼物，早已在暗中标好了价格( $ _ $ )`。这里的价格就是**多线程访问时所耗费的同步开销**

比如当共享变量要修改前，需要对该变量上锁，其他要访问该共享变量的线程必须等共享变量修改完成释放锁后才能继续执行。这期间线程等待所耗费的资源就是所谓的开销。关于同步异步、并发并行、互斥信号量等基础知识这里不再赘述

## 如果没有TLS变量
如果没有TLS变量,那么我们访问全局变量的时候,为了防止出现资源竞争,就必须给线程访问的时候上锁.
并且这个操作会导致额外的性能开销.

```cpp
#include <iostream>
#include <windows.h>

int g_number = 0x16;
CRITICAL_SECTION g_lock; // 使用互斥锁

DWORD WINAPI threadFunc1(LPVOID lpParam) {
    EnterCriticalSection(&g_lock);
    g_number = 0x27;
    printf("Global variable g_number in thread 1 is: %d\n", g_number);
    LeaveCriticalSection(&g_lock);
    return 0;
}

DWORD WINAPI threadFunc2(LPVOID lpParam) {
    EnterCriticalSection(&g_lock);
    g_number = 0x32;
    printf("Global variable g_number in thread 2 is: %d\n", g_number);
    LeaveCriticalSection(&g_lock);
    return 0;
}

int main() {
    InitializeCriticalSection(&g_lock); // 初始化线程锁

    printf("before thread start: %d\n", g_number);

    HANDLE threads[2];
    threads[0] = CreateThread(NULL, 0, threadFunc1, NULL, 0, NULL);
    threads[1] = CreateThread(NULL, 0, threadFunc2, NULL, 0, NULL);

    WaitForMultipleObjects(2, threads, TRUE, INFINITE);
    DeleteCriticalSection(&g_lock); // 结束线程锁

    printf("after thread end: %d\n", g_number);
    return 0;
}
```

输出是:

```cpp
before thread start: 22
Global variable g_number in thread 1 is: 39
Global variable g_number in thread 2 is: 50
after thread end: 50
```

发现会在线程中修改全局变量
## TLS变量
TLS变量即：同一个线程里面调用的各个函数都可以访问、但其他线程无法访问的变量（被称为static memory local to a thread 线程局部静态变量）

举个例子：线程A 修改TLS变量后线程B中的TLS变量不受影响，因为每个线程中都有一个TLS变量副本

```cpp
#include <iostream>
#include <Windows.h>

_declspec(thread) int g_number = 0x16;

DWORD WINAPI threadFunc1(LPVOID lpParam) {
	g_number = 0x27;
	printf("global variable g_number in thread 1: %d\n", g_number);
	return 0;
}

DWORD WINAPI threadFunc2(LPVOID lpParam) {
	Sleep(1000);
	printf("global variable g_number in thread 2: %d\n", g_number);
	return 0;
}

int main() {
	
	HANDLE hThread1 = CreateThread(NULL, 0, threadFunc1, NULL, 0, NULL);
	HANDLE hThread2 = CreateThread(NULL, 0, threadFunc2, NULL, 0, NULL);

	system("pause");
	return 0;
}
```

在这个函数中,程序会分别输出
会发现在第二个线程中,TLS全局变量没有被修改

```shell
global variable g_number in thread 1: 39
global variable g_number in thread 2: 22
```

## TLS回调函数的使用
### 首先需要在声明我们要使用TLS函数

```cpp
#ifdef _WIN64       //64位
     #pragma comment (linker, "/INCLUDE:_tls_used")  
     #pragma comment (linker, "/INCLUDE:tls_callback_func") 
#else               //32位
     #pragma comment (linker, "/INCLUDE:__tls_used") 
     #pragma comment (linker, "/INCLUDE:_tls_callback_func")
#endif
```

接着定义TLS函数

### 定义TLS回调函数

TLS回调函数的定义如下：

```cpp
typedef VOID (NTAPI *PIMAGE_TLS_CALLBACK) 
(PVOID DllHandle, DWORD Reason, PVOID Reserved);
```
---

| 参数  | 数据类型  | 数据含义         |
| --- | ----- | ------------ |
| 参数1 | PVOID | 指向DLL本身的实例句柄 |
| 参数2 | DWORD | 调用原因         |
| 参数3 | PVOID | 保留，固定为0      |

这里给出第二个参数调用原因的含义：
可以看到这里和DllMain函数的调用一样,所以TLS的执行流程我们可以类似DLL执行的流程

| 宏定义                | 值   | 描述                           |
| ------------------ | --- | ---------------------------- |
| DLL_PROCESS_ATTACH | 1   | 一个新进程已经启动，包括第一个线程            |
| DLL_THREAD_ATTACH  | 2   | 创建了一个新线程。此通知已发送给除第一个线程外的所有线程 |
| DLL_THREAD_DETACH  | 3   | 线程即将被终止。此通知已发送给除第一个线程外的所有线程  |
| DLL_PROCESS_DETACH | 0   | 进程即将终止，包括原始线程                |
|                    |     |                              |
### 注册TLS函数

```cpp
#ifdef _WIN64                           //64位     
#pragma const_seg(".CRT$XLF")     EXTERN_C const 
#else     
	#pragma data_seg(".CRT$XLF")        //32位     
	EXTERN_C 
#endif 
PIMAGE_TLS_CALLBACK tls_callback_func[] = { tls_callback,0 }; 
//这里是注册了tls_callback这个函数,还可以继续注册别的函数在这个指针数组中
#ifdef _WIN64                           //64位     
	#pragma const_seg() #else     
	#pragma data_seg()                  //32位 
#endif //_WIN64
```

### 使用示例

```cpp
#include <stdio.h>
#include<windows.h>
//编译器声明使用TLS
#ifdef _WIN64       //64位
#pragma comment (linker, "/INCLUDE:_tls_used")  
#pragma comment (linker, "/INCLUDE:tls_callback_func") 
#else               //32位
#pragma comment (linker, "/INCLUDE:__tls_used") 
#pragma comment (linker, "/INCLUDE:_tls_callback_func")
#endif

//定义TLS回调函数
void NTAPI tls_callback(PVOID Dllhandle, DWORD Reason, PVOID Reserved) {
    switch (Reason)
    {
    case DLL_PROCESS_ATTACH: {
        printf("DLL_PROCESS_ATTACH \n");
        break;
    }
    case DLL_THREAD_ATTACH: {
        printf("DLL_THREAD_ATTACH\n");
        break;
    }
    case DLL_THREAD_DETACH: {
        printf("DLL_THREAD_DETACH\n");
        break;
    }
    case DLL_PROCESS_DETACH: {
        printf("DLL_PROCESS_DETACH\n");
        break;
    }
    default:
        break;
    }
}

#ifdef _WIN64                           //64位
#pragma const_seg(".CRT$XLF")
EXTERN_C const
#else
#pragma data_seg(".CRT$XLF")        //32位
EXTERN_C
#endif
PIMAGE_TLS_CALLBACK tls_callback_func[] = { tls_callback,0 };
#ifdef _WIN64                           //64位
#pragma const_seg()
#else
#pragma data_seg()                  //32位
#endif //_WIN64

DWORD WINAPI threadFunc(LPVOID param) {
    while (true) {
        printf("线程运行\n");
        Sleep(200);
    }
    return 0;
}

int main() {
    CreateThread(0, 0, threadFunc, 0, 0, 0);
    while (true)
    {
        Sleep(-1);
    }
}
```

当我们将TLS函数中加入反调试API的时候,就完成了TLS反调试.

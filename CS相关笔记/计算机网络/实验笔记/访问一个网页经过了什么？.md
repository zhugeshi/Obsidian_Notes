## Windows
1. 打开 Wireshark
2. 主界面会列出很多网卡：Wi-Fi / Ethernet / 虚拟网卡（VMware/WSL）
3. 选一个“有波形跳动”的、你正在上网的网卡（通常是 **Wi-Fi** 或 **Ethernet**）我自己的是 Wifi，因为我现在在使用 Wifi 上网
4. 双击网卡开始抓包

> 如果你不确定哪个是对的：打开网页时哪张网卡波形明显飙升，那个就是。

# 开始抓包

首先选择一个喜欢的网址。为了让包更干净，建议你这样做：

1. 在 Wireshark 顶部点 **Capture → Restart**（或直接停止再开始）
2. 立刻在浏览器地址栏输入：`https://bilibili.com` 然后回车
3. 页面加载完成后，回到 Wireshark 点 **Stop** 停止抓包

这样你抓到的基本就是这次访问的主链路。

# 开始解析四条链路

## 什么是四条链路

- DNS：把名字变成地址（域名 → IP）
- TCP：把路打通且可靠（建立连接）
- TLS：把路上锁且验身份（加密 + 证书）
- HTTP：开始办正事（请求网页资源 + 返回内容）

## DNS：找到正确的IP

在 Wireshark 顶部过滤器输入：
- `dns`

你应该能看到：
- `Standard query A bilibili.com`
- `Standard query response A bilibili.com ...` （可能还有 AAAA：IPv6, A: IPv4）

**你要做的事**

1. 点开 DNS 响应包（response）
2. 展开：`Domain Name System (response)`
3. 可以找到下面的内容：

![image.png](https://cloud-map-bed-1351541725.cos.ap-nanjing.myqcloud.com/pic/20260305195357.png)

## TLS：证书加密查询

完整链路查看:

![image.png](https://cloud-map-bed-1351541725.cos.ap-nanjing.myqcloud.com/pic/20260306152314.png)

过滤器输入：`tls`
你要找的包通常是：

- `Client Hello`
- `Server Hello`
- `Certificate`
- `Server Hello Done`（TLS1.2 常见）
- `Application Data`（握手后就看不到明文 HTTP 了）
    

重点看 ClientHello
点开 `Client Hello`，展开：

- `Server Name Indication (SNI)`：这里能看到你访问的域名 immersivetranslate.com
- `Supported Versions`：TLS 版本
